# BEP Index

BOS Enhancement Proposals (BEPs) record the design direction behind major
architectural changes. They capture **point-in-time** decisions and may contain
detail that has since evolved — for the current reference, see
[Architecture](index.md).

The proposals live in the repository under `docs/BEP/`. Each link below opens the
source file on GitHub.
